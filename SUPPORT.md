# Support

For general plugin support, use the WordPress.org support forum:

https://wordpress.org/support/plugin/zactonz-ai-provider-ollama/

For development issues, feature requests, and reproducible bugs, use GitHub issues:

https://github.com/zactonz/zactonz-ai-provider-ollama/issues

Please include your WordPress version, PHP version, plugin version, Ollama connection type, relevant model name, and reproduction steps.

Do not report security vulnerabilities publicly. See [SECURITY.md](SECURITY.md).
