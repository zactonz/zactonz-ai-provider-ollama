# Security Policy

## Supported Versions

The latest stable release is supported for security fixes.

| Version | Supported |
| ------- | --------- |
| 1.1.x   | Yes       |
| 1.0.x   | No        |

## Reporting a Vulnerability

Please do not open a public issue for suspected security vulnerabilities.

Report security issues privately to Zactonz Technologies:

- Website: https://zactonz.com/
- WordPress.org support forum for non-sensitive support: https://wordpress.org/support/plugin/zactonz-ai-provider-ollama/

Include the affected version, environment details, reproduction steps, and the expected impact when possible.
